================================================================================
STEP-BY-STEP SETUP (First Time)
================================================================================

1. PREPARE WSL (one-time setup)
   ────────────────────────────

   In WSL terminal:

   sudo apt update
   sudo apt install -y arduino-cli
   arduino-cli core install arduino:avr

   Verify:
   arduino-cli version
   arduino-cli board list  (should be empty until Arduino connected)


2. COPY PROJECT TO WSL
   ───────────────────

   In WSL terminal (choose one method):

   METHOD A - Copy (safest, independent from Windows)
   mkdir -p ~/Projects
   cp -r /mnt/c/Users/artur/OneDrive/Документи/Claude/Projects/self-balancing-robot ~/Projects/self-balancing-robot

   METHOD B - Symlink (if you keep editing in Windows)
   mkdir -p ~/Projects
   ln -s /mnt/c/Users/artur/OneDrive/Документи/Claude/Projects/self-balancing-robot ~/Projects/self-balancing-robot

   METHOD C - Git (if using version control)
   mkdir -p ~/Projects
   git clone <local-or-remote-repo-path> ~/Projects/self-balancing-robot


3. VERIFY PROJECT IN WSL
   ─────────────────────

   In WSL terminal:

   cd ~/Projects/self-balancing-robot
   ls -la

   Expected files:
   - balance_v2/balance_v2.ino   (main firmware)
   - flash.sh                    (attach USB + sync + compile + upload)
   - sync.sh                     (Windows -> WSL mirror)
   - README.md
   - WSL_SETUP.md
   - QUICKSTART_WSL.sh
   - arduino-cli.yaml
   - .gitignore

   NOTE: easiest path is to skip the manual steps below and just run:
     bash "/mnt/c/Users/artur/OneDrive/Документи/Claude/Projects/self-balancing-robot/flash.sh" --all
   which syncs to the WSL copy, then compiles and uploads balance_v2.


4. CONNECT ARDUINO AND FIND PORT
   ──────────────────────────────

   In WSL terminal:

   arduino-cli board list

   Expected output:
   Port         Type              Board Name  FQBN            Core
   /dev/ttyUSB0 Serial Port (USB) Arduino Uno arduino:avr:uno arduino:avr

   Note your port! (usually /dev/ttyUSB0 or /dev/ttyACM0)

   If no Arduino appears, try:
   dmesg | tail  (see device messages)
   lsusb         (list USB devices)
   ls /dev/tty*  (list serial ports)


5. COMPILE SKETCH
   ──────────────

   In WSL terminal:

   cd ~/Projects/self-balancing-robot
   arduino-cli compile --fqbn arduino:avr:uno balance_v2

   Expected: "Compiling sketch..." followed by success


6. UPLOAD TO ARDUINO
   ──────────────────

   In WSL terminal (replace /dev/ttyUSB0 with your port):

   arduino-cli upload --fqbn arduino:avr:uno --port /dev/ttyUSB0 balance_v2

   Expected: "Uploading..." followed by success


7. MONITOR SERIAL OUTPUT
   ──────────────────────

   In WSL terminal:

   arduino-cli monitor --port /dev/ttyUSB0 --config baudrate=115200

   You should see:
   BALANCE_V2_READY
   PITCH 0.83 ERR 0.07 RATE -3.14 U 12
   PITCH 0.91 ERR 0.15 RATE -5.23 U 15
   ... (continuous telemetry)

   Press Ctrl+C to exit

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "Arduino not found" when running 'board list'
───────────────────────────────────────────────────────
Solution:
  1. Check USB cable is connected
  2. Try different USB port on computer
  3. Check permissions: sudo usermod -a -G dialout $USER
  4. Logout/login to apply group changes
  5. Verify: dmesg | tail -20


PROBLEM: "Permission denied /dev/ttyUSB0"
──────────────────────────────────────────
Solution:
  sudo usermod -a -G dialout $USER
  newgrp dialout  (apply immediately without logout)


PROBLEM: "Compilation takes forever" (using symlink)
─────────────────────────────────────────────────────
Solution:
  OneDrive/Windows filesystem is slow via /mnt/c
  Switch to Method A (true copy in WSL) instead of symlink


PROBLEM: "Arduino drivers not found" (Windows-specific, use WSL!)
─────────────────────────────────────────────────────────────────
Solution:
  This is exactly why we're using WSL!
  Windows drivers update constantly and break USB access
  WSL avoids this issue completely


PROBLEM: "board list shows nothing but Arduino is plugged in"
──────────────────────────────────────────────────────────────
Solution:
  Try: lsusb  (to confirm Arduino appears in USB bus)
  Try: dmesg | grep -i usb  (to see kernel messages)
  Try different USB port
  Try: arduino-cli board list --discovery-timeout=10000
